Podstawy programowania

1. Zmienna

Zmienna to pudełko na dane.

var wiek = 12;

2. Tekst

Tekst piszemy w cudzysłowie.

var imie = "Adam";

3. Działania

Komputer umie liczyć: + - * /

var wynik = 5 + 3;

4. Porównania

== to "czy równe", != to "czy różne", a < i > to mniejsze i większe. Wynik to true (prawda) albo false (fałsz).

5 > 3

5. If

If sprawdza czy coś jest prawdą.

if (wiek == 12) { alert("tak"); }

6. If i else

Else robi coś innego, gdy if nie jest prawdą.

if (wiek > 18) { alert("dorosły"); } else { alert("dziecko"); }

7. Oraz i lub

&& znaczy "i jednocześnie", a || znaczy "lub".

if (wiek > 10 && wiek < 15) { }

8. Pętla for

Pętla powtarza kod określoną liczbę razy.

for (var i = 0; i < 5; i++) { }

9. Pętla while

While powtarza kod, dopóki warunek jest prawdziwy.

while (wiek < 15) { wiek = wiek + 1; }

10. Funkcja

Funkcja to kawałek kodu z nazwą.

function hej() { alert("hej"); }

11. Funkcja z parametrem

Do funkcji można coś przekazać.

function powitaj(kto) { alert("Cześć " + kto); }

12. Tablica

Tablica to lista rzeczy. Pierwsza rzecz ma numer 0.

var owoce = ["jabłko", "banan", "gruszka"];

13. Długość tablicy

length mówi, ile rzeczy jest na liście.

owoce.length

14. Okienka

alert pokazuje wiadomość, prompt zadaje pytanie, a console.log pisze w konsoli (F12).

var x = prompt("Ile masz lat?");

15. Komentarz

Komentarz to notatka w kodzie. Komputer ją ignoruje.

// to jest komentarz

16. Bug

Bug to błąd w programie. Każdy programista je robi.
